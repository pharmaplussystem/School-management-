# School Monitor
A redesigned, original school-management dashboard with responsive layout and Supabase authentication foundation.

## Setup
1. Extract the ZIP.
2. Put your Supabase Project URL and anon/publishable key in `assets/js/config.js`.
3. Run `supabase/schema.sql` in Supabase SQL Editor.
4. Upload the folder to GitHub Pages.

The dashboard is intentionally different in branding, card treatment, graphics, navigation and spacing from the reference image. Full modules can be built on this foundation.
