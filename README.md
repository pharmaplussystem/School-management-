# School Management System (Starter MVP)

A responsive PHP + MySQL school management system starter.

## Included
- Admin dashboard
- Student registration/listing
- Teacher management
- Classes and subjects
- Attendance
- Fees/payment records
- Exams/results
- Role-ready login structure
- Responsive UI

## Requirements
- PHP 8.1+
- MySQL 8+
- Apache/Nginx (XAMPP/WAMP/LAMP works)

## Setup
1. Create a MySQL database named `school_management`.
2. Import `database/schema.sql`.
3. Copy the project into your web server directory.
4. Edit `config/database.php` if your MySQL credentials differ.
5. Open `/public/` in your browser.

Default demo login:
- Username: admin
- Password: admin123

Change the demo password before production use.
