# School Management System Foundation

1. Create a Supabase project.
2. Run `supabase/schema.sql` in Supabase SQL Editor.
3. Put your Supabase URL and anon/publishable key into `assets/js/config.js`.
4. Create a user under Supabase Authentication.
5. Open `index.html` or deploy the folder to GitHub Pages.

The package contains the responsive foundation and database tables for schools, profiles, students, parents, staff, classes and subjects. More modules can be added without replacing the foundation.
